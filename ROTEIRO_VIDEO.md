# Roteiro do vídeo - 5 a 8 minutos

## 1. Apresentação - até 40 segundos
Cada integrante aparece na webcam e fala:
"Olá, meu nome é [NOME COMPLETO]. Neste vídeo vamos apresentar a primeira etapa da DevShowcase API."

## 2. Projeto - 40 segundos
Mostrar o GitHub e a estrutura:
- controller
- dto
- entity
- repository
- service

## 3. Modelagem - 50 segundos
Explicar:
- Profile possui vários Projects.
- Project pode possuir várias Technologies.
- Project possui vários Feedbacks.

## 4. Postman - aproximadamente 4 minutos
Executar:
1. POST /api/profiles
2. GET /api/profiles/1
3. POST /api/technologies
4. GET /api/technologies
5. POST /api/projects
6. GET /api/projects

Mostrar cada request e sua resposta.

## 5. Encerramento - 30 segundos
Mostrar o banco com os registros e finalizar:
"Essa foi a demonstração da primeira etapa da DevShowcase API, contemplando modelagem, persistência, validações e endpoints REST."
